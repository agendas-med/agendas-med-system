## 📌 Sobre o Projeto

O AgendasPRO é um sistema desenvolvido para automatizar a rotina de marcações e gestão de clientes. A plataforma foca em eliminar conflitos de horários e organizar o fluxo de trabalho de profissionais e empresas, entregando uma interface rápida e de fácil navegação tanto para o administrador quanto para o cliente final.

## ✨ Funcionalidades Principais

- **Calendário Interativo:** Visualização em tempo real de horários disponíveis e bloqueados.
- **Autoagendamento:** Página dedicada para os clientes realizarem marcações de forma autônoma 24/7.
- **Gestão de Serviços:** Cadastro de diferentes tipos de serviços, precificação e tempo de duração personalizado.
- **Dashboard Administrativo:** Painel com o resumo diário de compromissos, status de atendimento e controle de clientes.
- **Design Responsivo:** Acesso otimizado para celulares, tablets e desktops.
